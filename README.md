# Power Outage Monitor  -Ukraine
Монітор відключення світла за графіком - Україна.
# Монітор відключень світла: ESP32-C3 Super Mini + 240х240 екран ST7789

На екрані: годинник, день тижня, дата, чи є світло зараз, коли наступна зміна, і графік на 24 години вперед (два рядки по 12 годин, зелене світло є, червоне немає, жовте можливо, сіре даних немає). Графік перевіряється раз на 10 хвилин, минулі клітинки зникають, застарілі доби видаляються. Інтерфейс українською, налаштування вводяться двома кнопками й запам'ятовуються.

Підключення екрана й кнопок (`config.h`): SCL=4, SDA=6, DC=5, RST=3, CS=7, BL=10, кнопка A=GPIO0, кнопка B=GPIO1.

## Встановлення
1. Arduino IDE з ядром **esp32** (Espressif), плата **ESP32C3 Dev Module**.
2. Бібліотеки: **Adafruit GFX**, **Adafruit ST7735 and ST7789 Library**, **ArduinoJson 7.x**.
3. **Tools -> Partition Scheme -> Huge APP (3MB No OTA/1MB SPIFFS).** Це обов'язково: база з 29 706 населених пунктів займає ~350 КБ, у стандартний розділ разом з Wi-Fi/TLS вона не влізе.
4. USB CDC On Boot: Enabled (для виводу в Serial Monitor). Завантажте скетч `ukraine_outage_monitor.ino`.
Файл `places_data.h` великий (1,5 МБ тексту): першу компіляцію IDE може "думати" довше.

## Перше налаштування (на екрані)
Мережа Wi-Fi (пароль вводиться кнопками, відомі мережі запам'ятовуються й підключаються самі) -> часовий пояс -> населений пункт -> черга.

Вибір населеного пункту двома шляхами:
* **Список:** Область -> Район -> (перша літера, якщо в районі понад 30 пунктів) -> Населений пункт. «Назад» у кожному списку.
* **Пошук:** перший пункт у списку областей «Пошук за назвою». Літери: A наступна, B попередня (коли літера не обрана, B стирає останній символ); літера фіксується сама за 1,5 с. Утримання A 3 с: вихід, B 3 с: шукати. У результатах біля назви показано `(область, район)`. Для однойменних сіл можна дописати слово області/району/громади: `іванівка обух` знайде лише Іванівки Обухівського району. Спершу показуються назви, що починаються з введеного, потім ті, що його містять.
* Довга назва в списку й на головному екрані біжить рядком. Вибраний рядок показує ще й громаду.
* Після вибору пункту пристрій запитує у джерела, які **черги** є в оператора цієї області, і пропонує їх списком (якщо джерело не відповіло, показує стандартні 1.1 ... 6.2). Для області з двома операторами (Дніпропетровська: ДТЕК і ЦЕК) спершу питає оператора.

Чергу для свого будинку дізнайтесь на сайті/в застосунку свого оператора: відкриті дані містять графіки по чергах, а не по окремих селах.

## Керування
| Дія | Що робить |
|---|---|
| A коротко | перевірити графік зараз (не частіше за раз на 15 с) |
| A утримувати 3 с | меню: населений пункт і черга / Wi-Fi / часовий пояс / оновити графік / назад |
| A+B утримувати 3 с | яскравість (A плюс, B мінус) |
| обидві кнопки при вмиканні | повне налаштування спочатку |
В усіх списках: A вниз, B вгору, утримання будь-якої кнопки 3 с вибирає.

Кружок у куті: зелений усе гаразд, жовтий дані застаріли (понад 30 хв) або помилка, червоний немає Wi-Fi. Під назвою: справа «Оновл. ГГ:ХХ» або текст помилки (наприклад «Помилка HTTP 404»), «Графік оновлено» 3 хв після зміни графіка.

## Звідки дані (важливо)
Архів `ukraine-energy-monitor-status` містить лише сторінку стану джерел, самих графіків у ньому немає. Тому дані беруться з відкритих джерел (таблиця в `sources.h`, до трьох адрес на оператора, пробуються по черзі):
* **YASNO API**: м. Київ, ДТЕК і ЦЕК у Дніпропетровській області.
* **Baskerville42/outage-data-ua**: Київ, Київщина, Дніпро, Одещина (ДТЕК).
* **yaroslav2901/OE_OUTAGE_DATA**: Хмельницька, Закарпатська, Львівська, Тернопільська, Чернігівська, Запорізька, Житомирська, Полтавська, Рівненська, Прикарпаття, Черкаська, Харківська.
* **findme88/poltava-outage-data** (Полтавщина), **milkmann/gpv-zoe-zaporizhzhia** (Запоріжжя), **samokisha/outage-data-if** (Прикарпаття), **olnet93/gpv-voe-vinnytsia** (Вінниччина).
* **mrkaktuz/outages-data** (інший формат, `FMT_INTERVALS`): Миколаївщина, а також запасні дзеркала ДТЕК (Київ, Київщина, Дніпро, Одеса) і Житомира.
Покрито 18 областей і Київ. Без відкритих машиночитних даних лишились Крим, Севастополь, Луганська, Донецька, Херсонська, Волинська, Кіровоградська, Сумська (дані лише на сайті з входом) і Чернівецька (єдиний знайдений репозиторій має формат без назв груп і давно не оновлювався). У списку вони позначені «-», а після вибору показують причину.

**Що підтверджено, а що ні.** Імена файлів усіх областей на `OE_OUTAGE_DATA` (зокрема `Cherkasyoblenergo.json` і `Kharkivoblenerho.json`, саме так, з «oblenerho»), формат YASNO та коди Києва й Дніпра звірено з проєктами ha-svitlo-yeah, ha-yasno-outages і UA-power-outages-monitor. Я не запускав розбір на живих даних з мережі й не компілював прошивку для ESP32 (перевірено лише обчислення графіка й часу на тестових даних). Якщо на екрані «Помилка HTTP 404», виправте адресу в `sources.h`; якщо джерело змінить формат, потрібна правка `schedule.h`. Чернівецька область публікує графіки лише в Telegram, тому її не підтримано.
